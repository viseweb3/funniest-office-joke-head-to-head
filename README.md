## The entry

One short line about office life — a real joke with a setup and a turn,
built on something anyone who has worked in an office recognises, with the
punchline last:

> Our coffee machine only takes exact change, like my manager only takes exact credit.

## Run it

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` (1–200 characters, UTF-8) and
prints it to stdout.
